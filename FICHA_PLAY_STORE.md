
## Descrição completa (máx. 4000 caracteres)
```
Frase do Dia é o app mais simples que você vai instalar: todo dia, uma
única frase inspiradora te espera — nada de rolar feed, nada de
distração.

COMO FUNCIONA
• Uma frase por dia, sempre nova.
• Nunca se repete até que todas as frases da base já tenham aparecido.
• Funciona sem internet — abra em qualquer lugar.
• Sem cadastro, sem login, sem complicação.

RECURSOS
• Compartilhe a frase do dia com seus amigos no WhatsApp, Telegram ou
  onde preferir.
• Ative um lembrete diário no horário que você escolher.
• Interface leve, rápida e sem distrações.

PRIVACIDADE EM PRIMEIRO LUGAR
O app não pede cadastro, não coleta dados pessoais e funciona
totalmente offline. Tudo fica guardado no seu próprio aparelho.

Baixe agora e comece o seu dia com uma frase por vez.
```

## Categoria sugerida
Estilo de vida (ou Saúde e bem-estar)

## Classificação de conteúdo
Livre para todas as idades — sem violência, conteúdo sexual, linguagem
imprópria ou temas sensíveis. No questionário de classificação do Play
Console, responder "Não" para todas as categorias de conteúdo sensível.

## Público-alvo e conteúdo
- Não é direcionado a crianças (mas não há motivo para restringir).
- Não contém compras dentro do app.
- Contém anúncios: **Sim** (banner via Google AdMob).

# Formulário de Segurança de Dados (Data Safety)

Este é o roteiro para o questionário "Segurança dos dados" do Play
Console, com base no que o app realmente faz.

## O app coleta ou compartilha algum dado do usuário?
**Sim** — apenas por causa do SDK de anúncios (AdMob). O aplicativo em
si não coleta nada.

## Dados coletados (via AdMob)
| Tipo de dado | Coletado | Finalidade |
|---|---|---|
| Identificadores de dispositivo (ID de publicidade) | Sim | Publicidade |
| Dados de interação com anúncios | Sim | Publicidade |

Marcar essas coletas como realizadas pelo **SDK terceirizado (Google
AdMob)**, não diretamente pelo desenvolvedor.

## Dados NÃO coletados
Nome, e-mail, telefone, endereço, localização precisa, contatos,
fotos, arquivos, histórico de navegação, informações financeiras,
saúde — nenhum desses é solicitado ou acessado pelo app.

## Os dados são criptografados em trânsito?
Sim (gerenciado pelo SDK do Google).

## O usuário pode solicitar exclusão dos dados?
Não aplicável da parte do desenvolvedor (não guardamos nada em
servidor). Para os dados de publicidade, o usuário controla pelas
configurações de privacidade do próprio Android (redefinir/excluir ID
de publicidade).
